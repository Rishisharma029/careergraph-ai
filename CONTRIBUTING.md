# Contributing to CareerGraph AI

Thank you for your interest in contributing to **CareerGraph AI**! We welcome contributions, bug fixes, feature proposals, and documentation enhancements.

## 🚀 Getting Started

1. **Fork the Repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/careergraph-ai.git
   cd careergraph-ai
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Run the local development server**:
   ```bash
   npm run dev
   ```

## 🛠️ Pull Request Process

1. Create a descriptive feature branch (`git checkout -b feat/amazing-feature`).
2. Ensure the production bundle builds without errors:
   ```bash
   npm run build
   ```
3. Commit your changes following clean commit guidelines:
   ```bash
   git commit -m "feat: add amazing feature"
   ```
4. Push to your branch and open a Pull Request against `main`.

## 📜 Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project, you agree to abide by its terms.
